## 2026-11-20 最终目标扩展为完整第一人称虚拟身体

用户已确认最终交付完整第一人称人物。包含双手、前臂、上臂、肩颈、躯干、骨盆、双腿、鞋及可在镜像和观察视角中显示的头部。现有坐姿手部任务持续作为第一验收入口。

分阶段实施如下。

1. 完成当前短前臂和袖口的同机位验收，清除近景断面与材质接缝。让肘部和上臂在坐姿活动范围内连接自然，用头位与双腕估计肩肘位置，限制肘反折、肩跳动和异常拉伸。姿态估计采用清楚的来源标识。
2. 加入肩颈、胸腹、骨盆和服装。绑定用户校准后的身高、臂长与坐姿高度，验证低头、转头、跨中线、双手交叉及桌沿动作的遮挡。支持左右手实测、镜像和辅助显示。
3. 加入下肢和脚部。先支持坐姿脚位与起坐显示，再加入站立及移动。由追踪器、宿主位移或动画驱动的部位记录各自来源。每增加一种驱动都检查失追、重定位和暂停恢复。
4. 完成通用头部和面部，以及全身绑定、LOD、镜像、观察相机和三款隔离宿主的安装验证。本人第一视角相机隐藏自身头部内表面，镜子与观察视角显示完整头部，并验证双目、影子和脖颈接缝。
5. 通过真实头显坐姿及站立检查后，记录完整身体的帧时、舒适度和穿模结果。研究中使用镜子或第三人称画面时将其显示方式纳入实验条件。

人脸首版设计采用原创通用成人面孔，保留自然五官和与手部一致的写实程度。提供有限的肤色、发型和体型选择，默认中性表情与普通服装。头像编号、外观参数和版本可随会话记录，固定实验条件下保持一致。更换外观允许先预览，并由研究方案决定正式试次之间是否允许切换。模型资源记录来源、作者、修改和许可。

实验知情同意材料说明虚拟身体的用途、外观选择、镜像及录像是否出现头像，参与者可报告不适并按研究流程暂停。通用形象的开发可以继续，参与者研究的伦理审查由研究负责机构依实际方案组织。[国家卫生健康委伦理审查办法](https://www.nhc.gov.cn/qjjys/c100016/202302/6b6e447b3edc4338856c9a652a85f44b.shtml)

## 接入约定

### 本轮可试装的双手

1. 在 Unity 2022.3 Built-in 测试工程中准备已有的 XR 宿主，启用对应设备的 OpenXR loader 与控制器配置。为双手启用内置 XR 模块、动画模块与 UGUI。在 Package Manager 的“从 tarball 安装”选择随附的 `com.unity.cloud.gltfast-6.13.1.tgz`。安装已有相同版本时可跳过此步。
2. 导入 `FirstPersonHands.unitypackage`，将 `Assets/VirtualHand/Prefabs/ElenaFF/FirstPersonHands.prefab` 拖到宿主追踪原点下作为直接子物体。现有 PICO Rig 可在建立 `rig.TrackingSpace` 后调用 `Instantiate(handPrefab, rig.TrackingSpace, false)`。追踪原点按米计，比例设为 1。若使用不同父节点，请将 `ControllerHandPair.trackingOrigin` 指向实际的追踪原点。
3. 腕部只接受同时有效的位置和旋转。无设备时双手隐藏；有手柄时左右手可各自跟随，握把模拟从张手到握拳。戴头显后分别对齐左右腕点与朝向。隔离娃娃机另接握把输入，整局结果见当前验证记录。
4. Unity 中可用 `Neuralife → VirtualHand → Export First Person Hands` 重新导出；保留包内的 Elena FF 作者署名。干净工程导入、正式项目的测试及桌面穿模复测见[本轮交付记录](../RESULTS.md)。

5. 第一视角预制件由宿主绑定坐姿身体中线和每侧腕部中立目标。镜像根据校准后的操作腕推算对侧手；失去操作手时，两手一起隐藏。娃娃机隔离副本可以从主菜单或暂停页打开“坐姿与手部校准”，单个手柄的摇杆与扳机可完成选择。

- 宿主提供追踪原点，负责头显相机、移动、转向、暂停和游戏规则。手模块消费带左右侧、时间戳、追踪有效位的腕部数据；光学追踪可用时单独接关节提供器。禁止把右手射线方向当成手腕旋转。渲染前允许刷新可见手部位姿，交互事件只在逻辑更新中派发一次。[Unity 追踪原点说明](https://docs.unity3d.com/Packages/com.unity.xr.core-utils@2.2/manual/xr-origin.html) · [Unity XR Hands](https://docs.unity3d.com/Packages/com.unity.xr.hands@1.4/manual/index.html)
- 第一视角保持头部自主。接触时区分传感器腕位与显示手的微调，记录二者偏差。在同一帧每个腕与指骨均只有一个写入方；桌面回放、任务辅助和现场追踪的切换要清空历史和未消费事件。
- 位置以米计，旋转为相对明确追踪原点的四元数。每手分开记录时间、位置/旋转有效性、当前控制源、辅助方式、抓取/释放结果及丢追踪恢复。默认只记录完成测试所需字段。EEG 意图不得伪装成患者真实手腕轨迹或逐指测量。
- 原型达标后用只含运行资产的可迁移包做一次新工程导入，检查左右手原 Prefab 的 glTF 导入依赖、法线、材质和 Elena 署名。回放数据、桌面场景与编辑器测量工具按需安装。
