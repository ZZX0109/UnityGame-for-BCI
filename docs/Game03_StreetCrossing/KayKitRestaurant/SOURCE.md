# 街角咖啡店的桌椅

餐桌、餐椅与原始调色纹理来自 Kay Lousberg 的 KayKit Restaurant Bits 1.0，固定版本为 153c8a7535b48237854cb54ff6890679f8c574d1。模型包内附 CC0 1.0 许可。[上游资产目录](https://github.com/KayKit-Game-Assets/KayKit-Restaurant-Bits-1.0/tree/153c8a7535b48237854cb54ff6890679f8c574d1/addons/kaykit_restaurant_bits/Assets/obj) · [上游模型许可](https://github.com/KayKit-Game-Assets/KayKit-Restaurant-Bits-1.0/blob/153c8a7535b48237854cb54ff6890679f8c574d1/addons/kaykit_restaurant_bits/Assets/LICENSE.txt)

原始 table_round_A_small_decorated.obj 和 chair_A.obj 以 CafeTable.obj 和 CafeChair.obj 导入，保留两份原始 MTL 及 restaurantbits_texture.png，Unity 材质使用同一张原始图集。一张桌和两把椅子共 1,612 个三角面，摆在咖啡店门垫东侧。餐桌按 0.74 倍、餐椅按 0.90 倍等比放置，桌面高 74 厘米，座面高 45 厘米。

本地将桌上两只瓶子各缩至原尺寸的 28%，桌牌缩至 40%，三者向桌心收拢，底部贴合桌面。源网格的拓扑和贴图坐标保留。
