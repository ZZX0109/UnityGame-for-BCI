## 打开与选择

在 Unity Hub 打开工程并载入 [StreetCrossingScene.unity](Assets/StreetCrossing/Scenes/StreetCrossingScene.unity)。直接点 Play 用键鼠测试。首页的“分步练习”可以直接进入任一阶段，也可以向下选择街区、任务及 A/B/C 固定配置。

| 阶段 | 实际完成条件 |
|---|---|
| 熟悉环境 | 沿人行道到达横道入口的路沿，注视可见的对面行人灯至少 0.6 秒。 |
| 单方向观察 | 在路沿向左看清来车道。前两阶段都在人行道内完成，走进车道需要重试。 |
| 双方向判断 | 在住宅街区观察左右来车，按行人信号安全过街到便利店。 |
| 复杂车流 | 在商业街确认双向四条车道，等待混合车流清空后到书店。 |
| 干扰和遮挡 | 在公交候车亭旁调整站位，确认被遮住的近车道和转弯来车后到咖啡店。 |
| 生活情境任务 | 完成咖啡店往返，两段均须重新观察并安全通过。 |

阶段完成记录与原有任务成绩分别保存。前两阶段不授予过街安全星，六个阶段均可直接重练。


| 街区 | T1 引导 | T2 标准：主要显示风险 | T3 挑战：独立观察 |
| --- | --- | --- | --- |
| S01 住宅社区 | 去对面便利店 | 在不同起始信号阶段判断出发时机 | 从便利店反向返回住宅入口 |
| S02 商业街 | 去书店，确认双向四条车道 | 在混合车型/排队遮挡下重新观察后去书店 | 识别药店，过街后沿人行道到实际药店门前 |
| S03 转角路口 | 去咖啡店，认识转弯和清空过程 | 自主选择安全观察站位后去咖啡店 | 去咖啡店后返回原住宅侧起点 |

任务稳定ID为`S01-T1`至`S03-T3`。A/B/C是同一任务的三组固定seed配置，不代表额外难度等级；相同任务版本和配置重开时应复现同样开局。T2的20/20/8秒预演必须完整推进信号与车流，不是只切灯色。

在课程第三至第六阶段，两侧观察分别记录。路沿等待时，如果信号、该侧车流风险发生变化，或距离上次有效观察已超过 10 秒，左上角会指出需要重看哪一侧。留在人行道上重新看清再出发，等待本身不扣分。原九项街区自由练习保留此前的成绩规则。

## 键鼠与返程

| 键鼠 | 作用 |
| --- | --- |
| WASD / 鼠标 | 连续行走 / 环顾街道 |
| Shift | 按住快步走 |
| E | 查看附近可见的提示牌 |
| Esc | 暂停／继续；设置页先返回 |
| R | 确认后从第一段重开整个任务 |

在路沿确认信号并主动观察各必需车道，再沿横道与人行道去实际目的地。不要穿过横道外车道直奔店招。暂停或失焦会冻结世界；舒适、字号、音量设置不是难度处罚。

往返任务到咖啡店后先显示本段回顾，选择“准备好了，继续返程”再走第二段。返程保留交通与信号进度，方向、进入条件及观察证据重新建立；去程观察和安全标记不能直接算作返程通过。重新开始会回到第一段，并重置本次任务的交通开局与观察记录。

## 安全成绩与推荐

只有整项任务各段均安全完成才记录成绩：信号进入、合法路线、进入前可见道路观察与移动碰撞等关键条件必须满足。安全完成基础1星；没有危险接近再加1星，没有静止接触再加1星。往返成绩取各段最低星，任一段关键违规时整项任务为0星，不能被另一段成功覆盖。等待与任务用时单独记录，不加减安全星，也没有抢时间奖励；长等待先提醒，不因合理等待强制失败。

每个任务、revision及A/B/C分别保存最高星和是否安全完成。反复完成同一配置不会增加不同配置完成数；同一梯度的三组配置均安全完成后推荐下一梯度，最高推荐T3。高阶可自由练习，但不会跳过未完成前序梯度的推荐。原有S01/S02/S03情境星级与舒适设置保留，新任务成绩独立存储。

观察记录来自相机朝向、道路可见性与停留时间，不是眼动或注意力测量。结果页分别解释每段信号、观察、路线、危险接近、静止接触和移动碰撞。
