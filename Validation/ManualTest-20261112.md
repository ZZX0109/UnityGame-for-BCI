# 第一轮实机测试 · 2026-11-12

使用本轮最新源码运行 PuzzleScene；旧 exe 不会包含本轮修改。建议先在 Unity Editor 游玩，确认编译无误后再构建 Windows。

| 项目 | 操作 | 应看到的结果 |
| --- | --- | --- |
| 初次进入 | 打开主菜单 | 标题、中文字体、关卡状态、滚动条清晰；底部主按钮可点击 |
| 不同窗口 | 1920×1080、1366×768、1280×1024、800×600；再拉宽窗口 | 宽屏左右、窄屏上下；标题与关卡区不交叠；弹窗按钮留在屏幕内 |
| 设置返回 | 主菜单进入设置按 ESC；游戏暂停后进入设置再按 ESC | 分别回到主菜单、暂停页；关闭设置不会直接恢复游戏 |
| 设置保存 | 改灵敏度、FOV、舒适模式；退出 Play 后再进入或重启 exe | 设置保留；恢复默认后数值和全屏同步 |
| 第一关 | 不低头，平视箱体，按 E 完成 | 箱体选中明确，平视可推；结算路程包含跟随位移，不应仍为 0 |
| 暂停恢复 | 正常行走时暂停再恢复 | 能继续移动，时间不包含暂停时长 |
| 动画中暂停 | 推动开始后稍等到箱子移动中段，再按 ESC | 动画与计时冻结；恢复后只完成这一次推动 |
| 动画中退出 | 同上，暂停后返回菜单、重新进入 | 玩家、箱子、计数恢复正常；没有旧动画继续改变关卡 |
| 动画中重置 | 同上，从暂停页重新开始 | 新关卡初始状态干净，可再次推动 |
| 撤销/重置 | 推箱后 Z；再连按 R | 位置与视角恢复；撤销瞬移不增加路程；重置清零本关计时/路程 |
| 多箱 | 第三、五、六关分别对准不同箱子 | 高亮、编号提示、实际推动对象一致；不能从相邻箱缝穿过 |
| 死锁 | 把箱子推入非目标角落，再撤销 | 提示常驻，撤销后消失；可继续正常操作 |
| 八关与存档 | 顺序通关；退出重进 | 关卡解锁和最佳成绩保留；结算“下一关”正确 |
| 稳定性 | 反复切关/重置 20 次，观察 Console 与 Profiler | 无错误；高亮材质不会随切关无限增长；记录明显卡顿 |

没有历史存档时，顺序完成即可解锁后续关卡，不要改动正式成绩来绕过验收。

发现问题请记录：关卡、分辨率、操作顺序、预期/实际结果、Console 第一条错误（含堆栈），必要时截图或短录屏。
画面手感和实际性能本轮留给实机测试，不用自动测试数量代替这些结论。
