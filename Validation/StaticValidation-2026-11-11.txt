依据《FirstPersonSokoban 优化版代码审查》。范围约束：不重新开发、不推翻架构、

10.1 逐文件修改清单（修改前问题 → 修改方式 → 测试证据）

1) Scripts/Core/PuzzleGameManager.cs
   前：Resume() 写 SetInputLocked(Phase == Playing)，条件反了 —— 正常恢复后玩家被
       锁死，动画中恢复反而解锁；StartCoroutine(AnimatePush) 不保存句柄，暂停后
       经 ShowMenu / RestartLevel 恢复 timeScale 会让旧协程继续操作已销毁的箱子；
       Board.ApplyPush 在动画开始前已提交，中途退出留下半新半旧状态。
   改：Resume 改 SetInputLocked(!isPlaying)、LockCursor(Playing || Animating)；
       引入推动事务 pushRoutine + pendingSnapshot，撤销记录只在动画完整结束后入栈；
       CancelActivePush(rollback) 分别在 LoadLevel（不回滚，整关重建）与 ShowMenu
       （回滚箱子 / 玩家位置 / 视角 / 统计，不增加 UndoCount）调用；
       RestartLevel / StartLevel 不再用 Phase==Animating 早退拦住事务；OnDestroy 兜底；
       RefreshDeadlock 改分帧协程 + generation 取消 + 局面缓存；多箱提示显示「第 N 号箱」。
   证：PlayMode ResumeFromPlaying_ / ResumeFromAnimation_ /
       CancelPushThenReturnToMenu_ / CancelPushThenRestart_ / DeadlockSearch_（5 项）。

2) Scripts/Core/DeadlockDetector.cs
   前：IsDeadWallLine「贴墙且整行无目标」把「墙只有一小段、可沿墙滑到开口再转向
       另一行目标」的可解局面误报为无解（审查反例地图）。
   改：删除 IsDeadWallLine / HasGoalAlongRow / HasGoalAlongColumn；改由 BoardState 的
       反向推动可达性静态死格表判定（充分条件，只漏报不误报）；保留非目标角落与
       2x2 冻结；拆出 TryEvaluateStatic（瞬时） / CreateSession（分帧） /
       Classify / Signature，同步 Evaluate 仅供测试与编辑器工具使用。
   证：EditMode WallHasExit_SolvableStateIsNotDeadlocked（旧实现必失败）、
       Deadlock_StaticDeadSquareTableKeepsTrueWallDeadlock（原第二关 (3,1) 仍判死锁）、
       PlayMode DeadlockHint_（撤销后清除提示）。

3) Scripts/Core/BoardState.cs
   前：无静态死格信息；Restore 会把系统取消的动作也算成玩家撤销。
   改：新增 IsStaticDeadSquare（从所有目标做反向推动 BFS，按 BoardState 懒计算缓存）
       与 Rollback（回滚箱子 / 站位 / 累计推动数，不增加 UndoCount）。
   证：EditMode BoardState_RollbackRestoresBoxesWithoutCountingAsUndo、
       Deadlock_StaticDeadSquareTableKeepsTrueWallDeadlock。

4) Scripts/Core/LevelSolver.cs
   前：单次同步 BFS，状态键含玩家精确坐标；运行期每次推动在主线程同步跑最多 6000 状态。
   改：新增可分帧的 SolverSession（Step(maxExpansions)），状态键把同一玩家可达区域
       归并为其代表格；同步 Solve 复用同一会话，避免两套算法产生不同结论。
