# 认知训练实验室 · 视觉候选版

目标：半写实、整洁、温暖的实验室。使用中性色作为主要面积，青色只标记可交互/待归位状态，绿色表示完成，橙色表示注意或危险操作。

## 已实现

| 层级 | 实现 | 主要文件 |
| --- | --- | --- |
| 房间身份 | 完整天花、墙板、踢脚线、观察窗、服务门、显示屏、通风口、顶梁和灯槽 | `LabEnvironment.cs` |
| 材质层次 | 程序生成低对比颗粒、板缝、粗糙度；白灰壳、石墨饰件、缎面金属 | `LabMaterials.cs` |
| 光照 | 冷白主光、暖/冷辅光、室内按需反射；观察点避开墙和初始箱子 | `LabEnvironment.cs` |
| 训练模块 | 倒角外壳、抓手槽、编号牌、深色护角、细状态条；静态装饰按材质合批 | `TrainingModuleVisual.cs` |
| 感应台 | 低矮嵌入式设备、感应环、对齐刻度；完成时一次扫光/淡出 | `SensorPlatformVisual.cs` |

加载、撤销和回滚只同步目标状态，不触发新归位音效/扫光。新完成反馈在推动事务成功后触发。
重置/切关时释放房间所有材质、纹理、Mesh；声音由 Bootstrap 所有；预览纹理由菜单所有。

## 性能边界

- 每关 13 个共享材质，6 张 128×128 程序纹理及 mipmap，约 0.5 MiB 原始纹理数据。
- 每关最多 1 个阴影主光、3 个无阴影补光、1 个 128 px 反射探针。反射只按需捕获，不逐帧刷新；批处理不捕获。
- 菜单预览使用 1024×288 RenderTexture，独立 31 层、无有效 Collider，捕获一张静态图后关掉整个舞台，不持续渲染。
- 原始 Tile/Box Collider 和网格保持不变；装饰创建时立即禁用 Collider 后销毁。
- 原有按帧预算的死锁搜索继续保留。没有通过提高求解预算或修改 Time.timeScale 来追求视觉效果。

这些是代码中的限制，不是实测 FPS/GC 结果。实际装饰 Renderer 数、载入开销、反射捕获和帧耗时需在目标 Windows 机器用 Profiler 检查。

## 需要实机确认

1. 主菜单能显示设备预览，中文和标题不截断；800×600、1280×1024、1920×1080及超宽窗口布局正常。
2. 游戏房间有天花、墙面设备和照明层次，墙面无明显闪烁或共面条纹，模块编号清楚。
3. 灰白模块和目标圈容易区分；选中、拒绝推动、归位的颜色/声音一致。
4. 推动成功才播放归位反馈；撤销、返回菜单、重置不会残留旧扫光或旧房间。
5. 静音确实无提示音；环境音默认关闭，开启后足够安静；舒适模式无明显放大/闪烁动效。
6. Player 构建与 Editor 观感一致，特别是粗糙度/金属和高亮边框；保留材质用于避免运行时 Shader 组合被移除。
7. 反复切关/重置20次观察资源增长，记录进入关卡/首次反射捕获时的帧耗时。

未进行 URP 迁移、烘焙光照、照片级扫描资产、AO/Bloom/晕影后处理；不能将这一版称为已完成实渲或已通过性能验收。
