# 开发优化 · 2026-11-13

## 关卡辨识与引导

每张关卡卡片加入实际地图的墙体/走道轮廓缩略图。使用 Unity UI 网格直接绘制，按地图长宽比缩放，不创建相机、RenderTexture 或外部图片；预览不显示箱子、目标和解法。既有滚动列表、关卡编号与解锁行为保留。

HUD 左上角增加目录已有的本关机制说明，例如“双箱互阻 · 让位后回推”。不改关卡 ID、revision、顺序、推动/撤销逻辑或死锁提示。难度顺序调整应在实际完成时间、绕行与撤销负荷测量之后决定。

## 完整路线回归

`LevelWalkthroughTests` 新增八项正常 PlayMode 用例。每项加载真实 PuzzleScene，从地图出生点开始，沿独立求解并固定的路线通过 CharacterController 实际行走，转动相机后通过真实射线选箱与 `TryPush` 推动。没有传送到推箱位置，没有直接修改棋盘、箱子或完成标志。

用例校验地图哈希、稳定 ID、revision、逐步站位、推动数、实际位移、完成阶段，以及旧解锁保留和旧图成绩隔离。固定路线离线复核共 195 个行走动作、93 次推动，全部合法；这只证明路线数据，不证明引擎内碰撞和视线成功。
